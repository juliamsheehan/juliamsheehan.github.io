2 Your Coding Tools

You already know these three coding ideas. Game makers use them all the time — and so will you! Press Try it on each one. 👇

➡️ Sequence

One step after another, in order.

Program: step → step → step

🔁 Loop

Do something again and again without writing it a bunch of times.

Program: Repeat 4 times → step

🔀 Conditional

IF something is true, THEN do this.

🔑🚪

Program: IF I have the key, THEN the door opens

🦊 Pip says: In your game, your moves are a sequence, a countdown timer is a loop, and a rule like “IF I touch a gem, THEN +1 point” is a conditional. You'll build all three!

3 Build your World

Design your level: drop a tool, then click (or drag) on the grid to place it.

How to build

  1. Place 1 hero start and 1 goal (you need both!).
  2. Add walls to make a path, and gems to collect.
  3. Try a key + door (the door opens only if you grabbed a key — a conditional!).
  4. Add hazards to dodge.

3 Code the Brain 🧠

Give your game its rules! Drag blocks (or click a hat then a block) to build sequences, loops, and conditionals.

4 Play & Test 🎮

Move with the arrow keys (or the buttons). Does your code work the way you planned? If not — that's a bug to fix. Real designers try, try again! 💪

5 Share & Improve

The best part of finishing a project is sharing it! Send your game to a friend, watch them play, and listen to their ideas. 🎉

Watch a friend play and ask:

  • Did anything not work the way you expected?
