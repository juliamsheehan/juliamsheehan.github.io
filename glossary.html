📖 Glossary & Links

One-line definitions for every term on this site. Type to filter — it searches names and definitions.

37 terms

Agent
A model placed in a loop with tools and a goal — it plans, acts, observes the result, and repeats until done. See Fundamentals.
Agentic
Describes AI that acts on its own toward a goal (multi-step, tool-using) rather than answering a single question.
API (model API)
A way to call a model from your own code so you can build AI features into software.
Artificial Intelligence (AI)
The broad goal of getting machines to do things that seem intelligent.
Autocomplete (ghost text)
Grey inline suggestions in your editor that finish the current line or block; press Tab to accept.
Chain of thought
A model working through intermediate reasoning steps before giving a final answer; the basis of reasoning models.
Context window
The maximum amount of text (in tokens) a model can consider at once — its short-term memory. See Fundamentals.
Deep learning
Machine learning using many-layered neural networks; strong on messy data like images and language.
Embedding
A list of numbers (a vector) that captures the meaning of a piece of text so similarity can be measured. See Fundamentals.
Few-shot prompting
Including a couple of example input→output pairs in your prompt so the model copies the pattern.
Fine-tuning
Extra training of a general model on narrower examples so it specializes in a style, format, or task.
Function calling
See Tool use — the model asks your software to run a function and uses the result.
GPT
Generative Pre-trained Transformer — a family of LLMs; also a common shorthand for that style of model.
Hallucination
When a model states something false with full confidence, because it produces likely-sounding text, not verified fact. See Fundamentals.
Inference
Running a trained model to get an answer (as opposed to training it). Every prompt you send is inference.
Knowledge cutoff
The date a model's training data stops; it won't reliably know newer events unless given the info.
LLM (Large Language Model)
A large neural network trained on text that predicts the next token; the engine behind today's AI assistants.
Local / on-device model
An open-weight model run on your own machine — private and offline, usually smaller than cloud models.
Machine learning (ML)
Getting programs to learn patterns from examples instead of being given hand-written rules.
MCP (Model Context Protocol)
A shared standard — the “USB-C for AI” — for connecting assistants to tools and data. See Tools.
Multimodal
A model that handles more than text — also images, audio, or video. See Fundamentals.
Neural network
A model loosely inspired by brain cells, made of layers of simple units that learn patterns from data.
Open-weight model
A model whose trained parameters are published, so anyone can download and run it (e.g. Llama, Mistral).
Parameters
The internal numbers a model learns during training; more parameters (billions) generally means more capacity.
Pre-training
The first, expensive stage where a model learns general patterns from a huge pile of text and code.
Prompt
The text you send a model. Prompt engineering is wording it well to get a better answer. See Apply.
RAG (Retrieval-Augmented Generation)
Fetching relevant documents and adding them to the prompt so the model answers from real sources — an “open-book exam.” See Fundamentals.
Reasoning model
A model trained to “think” through steps before answering; better at logic, math, and multi-step tasks. See Fundamentals.
RLHF
Reinforcement Learning from Human Feedback — tuning a model toward answers humans rate as helpful; what made assistants pleasant to use.
Semantic search
Search by meaning (using embeddings) rather than exact keywords, so related phrasing still matches.
System prompt
A standing, behind-the-scenes instruction that shapes every reply in a conversation.
Temperature
A dial for randomness: low = focused and repeatable, high = varied and creative. See Fundamentals.
Token
A word-chunk the model reads and writes; ~¾ of a word in English. Pricing and context limits are counted in tokens. See Fundamentals.
Tool use
Letting a model trigger real actions (run code, search, query a DB) and use the results; the foundation of agents. See Fundamentals.
Training
The process of adjusting a model's parameters from data so it gets better at predicting/answering.
Transformer
The 2017 neural-network architecture, built on “attention,” that underpins all modern LLMs. See Timeline.
Vector database
A store optimized for embeddings, so you can quickly find the text closest in meaning to a query — the retrieval half of RAG.
