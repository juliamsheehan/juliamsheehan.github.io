AI in one minute (the mental model)

If you remember just one picture, make it this one. Today's AI coding tools are all built on the same core idea:

💡 In plain English

A large language model (LLM) is a very good “predict the next word” machine. It read a huge chunk of the internet and learned the patterns in language and code. You give it text (a prompt); it continues that text one piece at a time, guessing what's most likely to come next. That's it. Everything else — chat, coding assistants, agents — is that engine wrapped in clever plumbing.

1️⃣

It predicts

It doesn't “look things up” or “know” — it produces the most likely next text based on patterns. Great at language and code, but it can be confidently wrong.

2️⃣

Context is everything

It only knows what's in front of it right now (your prompt + files you share). Give it the right context and it gets dramatically better.

3️⃣

You stay the pilot

It's a fast, tireless assistant — not an authority. You review, test, and decide. Trust, but verify.
